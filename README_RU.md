## О Winky

**Winky** — это кроссплатформенный десктопный голосовой ассистент, который помогает быстро преобразовывать голос в текст
и выполнять интеллектуальные действия на базе LLM. Благодаря удобному плавающему оверлею микрофона вы можете
взаимодействовать с Winky из любого места на экране, что делает его идеальным для рабочих процессов.

Winky поддерживает как облачную, так и локальную обработку ИИ, давая вам гибкость выбора между скоростью и приватностью.
Независимо от того, нужны ли вам быстрые голосовые команды, транскрипция или ответы на базе ИИ, Winky готов помочь.

## О репозитории

Этот репозиторий содержит исходный код Winky — кроссплатформенного десктопного приложения, построенного на **Tauri +
React + Vite**. Приложение предоставляет современный и эффективный опыт работы с голосовым ассистентом с поддержкой
множества провайдеров ИИ и локальных вариантов обработки.

## 🚀 Основные возможности

- **Локальная обработка без подписки Winky** - облачные провайдеры могут взимать плату за API

## 🎯 Как использовать

### 1. Настройка

1. Откройте приложение `Winky`
2. Пройдите начальный мастер настройки:
    - Войдите в свой аккаунт (OAuth аутентификация)
    - Настройте ваши API ключи:
        * `OpenAI API key` (получите на [platform.openai.com](https://platform.openai.com))
        * `Google AI API key` (получите на [console.cloud.google.com](https://aistudio.google.com/api-keys))
3. Выберите **режим распознавания речи**:
    - `Cloud` - использование облачной транскрипции (OpenAI Whisper, Google AI)
    - `Local` - использование локального fast-whisper для приватности и скорости
4. Настройте **параметры LLM**:
    - Выберите предпочитаемого провайдера LLM
    - Выберите модель, подходящую для ваших нужд
5. **Настройте быстрые действия**:
    - Настройте пользовательские горячие клавиши для действий
    - Создайте и настройте ваши рабочие процессы действий

### 2. Использование

1. Используйте **плавающий микрофон** для начала распознавания голоса
2. Произнесите вашу команду или вопрос
3. Получите мгновенные ответы и действия на базе ИИ
4. Используйте **горячие клавиши** для быстрого доступа к частым действиям
5. Откройте профиль, действия и настройки из главного окна

### 3. Советы по использованию

- Расположите плавающий оверлей микрофона там, где вам удобно
- Настройте горячие клавиши под ваш рабочий процесс
- Используйте локальное распознавание речи для лучшей приватности
- Практикуйтесь с разными командами для лучших результатов

## Локальное использование

Примеры ниже реализованы и протестированы на `Windows 11`. Шаги могут отличаться на других системах.

### Ассистент работает в два этапа:

1. #### Транскрипция аудио

2. #### Получение ответа от LLM

### Каждый этап может быть запущен локально.

Облачные режимы транскрипции и LLM не являются локальными: они отправляют
аудио, текст или оба типа данных провайдеру, выбранному в настройках. Действуют
условия хранения данных, оплаты и приватности этого провайдера. Если данные
должны оставаться на устройстве, выберите локальное распознавание речи и
локальную LLM.

### Локальное распознавание речи

1. В настройках `Winky` выберите `Mode -> Speech Recognition` = `Local`.

2. В настройках `Winky` выберите одну из моделей `Model -> Speech Recognition`

3. В настройках `Winky` выберите `Local transcription device`: `GPU` (Графика/NVIDIA) или `CPU` (Процессор)

Локальный сервер распознавания речи будет автоматически установлен и управляться Winky.

### Локальная обработка LLM

Минимальная рекомендуемая конфигурация:

- CPU - 4 ядра / 8 потоков
- GPU - 6 GB VRAM
- RAM - 16 GB

1. В настройках `Winky` выберите `Mode -> LLM` = `Local`.
2. В настройках `Winky` выберите `Model -> LLM` из доступных моделей (модели Ollama)

3. #### Установите Ollama
   https://ollama.com/

4. #### Скачайте выбранную ранее модель
   ```shell
   ollama pull <model-name>
   ```

5. #### Запустите Ollama
   ```sh 
   ollama serve
   ```

### Первое использование после открытия программы будет медленнее, так как при локальном использовании модели ИИ будут загружены в GPU или RAM, что занимает время. Перед важными задачами сделайте тестовый запуск, чтобы последующие вызовы были быстрее.

### Локальная разработка

#### Требования

- Node.js LTS и npm
- стабильный Rust
- [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/)

#### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/Artasov/winky.git
cd winky

# Установите зависимости
npm ci

# Соберите проект
npm run build

# Запустите в режиме разработки
npm run dev
```

#### Структура проекта

```
src/
├── renderer/       # React renderer процесс (UI)
│   ├── app/        # Логика приложения и хуки
│   ├── components/ # React компоненты
│   ├── context/    # React context провайдеры
│   ├── features/   # Модули функций
│   ├── services/   # API и сервисный слой
│   ├── windows/    # Компоненты окон
│   └── ...
├── shared/         # Общие типы и утилиты
└── ...
src-tauri/
├── src/             # Rust бэкенд (Tauri)
└── ...
```

#### Доступные команды

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка проекта
- `npm run build:renderer` - сборка только renderer (фронтенд)
- `npm run dev:renderer` - запуск только dev сервера renderer
- `npm run lint` - проверка типов TypeScript
- `npm run typecheck` - то же, что и lint
- `npm run preview` - предпросмотр собранного фронтенда

#### Сборка для разных платформ

```bash
npm run build
```

Tauri собирает приложение для текущей host-платформы и сохраняет installers и
bundles в `src-tauri/target/release/bundle`. Для кроссплатформенного release
нужен runner каждой целевой операционной системы; для macOS также требуются
Xcode Command Line Tools.

#### Технологии

- **Tauri** - кроссплатформенный фреймворк для десктопных приложений
- **React** - библиотека UI
- **TypeScript** - типизированный JavaScript
- **Tailwind CSS** - utility-first CSS фреймворк
- **Vite** - инструмент сборки и dev сервер
- **OpenAI API** - интеграция с ИИ
- **Google AI API** - интеграция с ИИ
